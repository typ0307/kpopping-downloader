# 💙 Kpopping Downloader & Viewer

kpopping.com의 고화질 K-POP 아이돌 사진(KPics)을 편하게 감상하고 **원본 화질과 파일명 그대로** 다운로드할 수 있는 데스크톱 애플리케이션입니다.
파이썬(Python)이나 코딩을 전혀 몰라도 아래 가이드만 따라 하시면 5분 안에 실행할 수 있습니다!

---

## ✨ 주요 기능

- **강력한 봇 차단 방지 🛡️**: 서버가 차단하지 않도록 실제 사람(크롬 브라우저)처럼 똑똑하게 우회하여 사진을 가져옵니다.
- **원본 파일명 유지**: `001.jpg` 같은 임의의 이름이 아닌, 서버에 등록된 원본 이미지 파일명 그대로 깔끔하게 저장합니다.
- **선택적 다운로드**:
  - `현재 사진 1장 다운로드`: 뷰어에 띄워진 맘에 드는 사진 한 장만 즉시 저장!
  - `전체 다운로드`: 앨범 제목으로 자동 폴더를 만들고 앨범 내 전체 사진을 싹쓸이 저장!
  - `다운로드 중지`: 다운로드 중 언제든 작업을 멈출 수 있습니다.
- **고화질 뷰어 & 썸네일 슬라이더**: 마우스 드래그로 뷰어와 썸네일 영역 크기를 자유롭게 조절하며 감상하세요.

---

## 📖 사용 방법 (How to Use)

프로그램이 실행되면 다음 순서대로 사용하시면 됩니다.

1. **주소 복사하기**: Kpopping 사이트에서 다운로드하고 싶은 앨범 페이지의 주소를 복사합니다.
   > **✅ 올바른 주소 입력 예시:**
   > `https://kpopping.com/kpics/260811-karina-at-synk-complxity-world-tour-in-taipei`
2. **붙여넣고 불러오기**: 프로그램 상단 입력창에 주소를 붙여넣고 **[불러오기]** 버튼을 클릭합니다.
3. **감상 및 저장**: 썸네일을 클릭하며 메인 뷰어에서 고화질로 감상한 뒤, 원하는 경로를 지정하고 **[다운로드]** 버튼을 누르면 끝!

## 🚀 초보자를 위한 설치 및 실행 가이드 (코딩 몰라도 됨!)

복잡한 파이썬 설치 과정 없이, 차세대 패키지 매니저인 `uv`를 사용해 명령어 몇 줄로 모든 환경을 자동 세팅합니다.

### 1단계: 필수 도구(Git) 설치하기

코드를 다운로드하기 위해 Git이 필요합니다.

- **Windows**: [Git 다운로드 페이지](https://git-scm.com/download/win)에서 `64-bit Git for Windows Setup`을 받아 기본 설정(Next)으로 설치합니다.
- **Mac**: 터미널(Terminal)을 열고 `git --version`을 입력하면 자동으로 설치 팝업이 뜹니다.

### 2단계: 터미널 열기

- **Windows**: 시작 메뉴에서 `cmd` 또는 `명령 프롬프트`를 검색해서 엽니다.
- **Mac**: `cmd + space`를 누르고 `Terminal` 또는 `터미널`을 검색해서 엽니다.

### 3단계: 소스 코드 다운로드 (Clone)

터미널에 아래 명령어를 복사하여 붙여넣고 엔터를 칩니다.

```bash
git clone [https://github.com/본인계정명/kpopping-downloader.git](https://github.com/본인계정명/kpopping-downloader.git)
cd kpopping-downloader
```
